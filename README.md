# FinanceFlow Full Stack

A personal finance management application built with Spring Boot, React and PostgreSQL.

## Features
- JWT authentication and role-based access
- Income and expense tracking
- Custom transaction categories
- Monthly budgets
- Dashboard summaries and analytics
- Date/category/type filtering
- CSV transaction export
- Secure REST APIs with validation
- PostgreSQL persistence with Flyway
- Docker Compose

## Stack
Java 21 · Spring Boot · Spring Security · JPA/Hibernate · PostgreSQL · React · Vite
